## Abstract

Cyber-Physical Systems (CPS) are increasingly reliant on AI-driven Digital Twins (DTs) for intelligent monitoring, predictive maintenance, and control. This work presents a deep learning-based anomaly detection framework employing LSTM and Autoencoders to detect replay attacks in real time.

## 🎯 Key Results

- **LSTM Model**: 91% accuracy, 90% precision
- **Autoencoder**: 88% accuracy, 87% precision  
- **Isolation Forest**: 73% accuracy (baseline)

## 📊 Dataset

This project uses the [NASA CMAPSS dataset](https://data.nasa.gov/Aerospace/CMAPSS-Jet-Engine-Simulated-Data/ff5v-kuh6).
